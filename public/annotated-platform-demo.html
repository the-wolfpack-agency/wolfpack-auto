Admin Portal — System Dataflow Map

Every admin action writes to the same data pipeline that powers the public site. No siloed data — admin decisions feed the learning loop.

/admin — Command Center
KPI Cards Live DB Queries Recent Leads
Data sources: GET /api/admin/stats → vehicles table (total/available/sold), leads table (new/qualified/total), avg days on lot, conversion rate.
Audit: Every admin login → audit_log table with timestamp, IP, session ID.
MFA gate: JWT must have mfa_verified=true or access is blocked at middleware.
/admin/inventory — Vehicle Management
vehicles table VIN Decode API Audit Log
Reads: SELECT from vehicles WHERE dealer_id (RLS enforced).
Writes: PATCH /api/admin/inventory/[vin] — price, status, photos → audit_log("inventory.update").
Quick-add: POST /api/admin/quick-add decodes VIN, pre-fills make/model/year from NHTSA API.
Image upload: POST /api/images/upload — session dealer_id enforced (no client-supplied IDs). Stores to S3-compatible Blob.
/admin/leads — Lead Pipeline
leads table Lead Scoring ML Audit Log
Reads: GET /api/admin/leads — filter by status/source/date, full PII decrypted server-side (AES-256-GCM).
Status changes: PATCH /api/admin/leads/[id] → audit_log("lead.status_change") — full immutable history.
Lead Score: POST /api/admin/leads/score-all — ML model re-scores all leads by predicted conversion probability. Scores stored back to DB.
Bulk ops: POST /api/admin/leads/bulk — assign/archive/tag multiple leads in one transaction.
/admin/analytics — Intelligence Dashboard
analytics_events Funnel Metrics Trade-In KPIs
Source: GET /api/admin/analytics/dashboard — aggregates analytics_events, leads, trade_in_estimates tables.
Trade-in funnel: estimates last 30 days, leads converted, conversion rate, avg estimated value — all live from DB.
Custom queries: POST /api/admin/analytics/query — natural-language-to-SQL via AI (dealer asks "which vehicles had the most VDP views this week?").
Feedback loop: Admin actions (price changes, lead dispositions) write events that feed Insight #39 — price change → conversion correlation.
/admin/pricing — AI Pricing Recommendations
pricing_recommendations Apply / Dismiss Market Data
Source: pricing_recommendations table — generated_at, recommended_price, confidence, reasoning.
Apply: PATCH /api/admin/pricing/[vehicleId] with action="apply" → updates vehicles.price + marks rec applied_at. Insight #35 tracks uptake rate.
Dismiss: action="dismiss" → marks dismissed_at. Dismissal patterns train future recommendation confidence.
Insight #39: After price change, system correlates days-to-sale and VDP view velocity — proving or disproving each recommendation.
/admin/trade-in — Trade-In Pipeline
trade_in_estimates Lead Conversion Analytics Bridge
Source: trade_in_estimates table — all estimates with vehicle info, condition, price range, submitted_at.
Funnel view: Step drop-off rates (step 1→2→3→4→submitted) — shows exactly where customers abandon.
Lead bridge: Estimates that convert to leads (contact form submitted) are linked by estimate_id — Insight #34 maps the journey.
AgenticQA: scripts/ingest_trade_in_data.py ingests trade-in metrics into the learning system — platform improves estimate accuracy over time.
/admin/compliance — Regulatory Dashboard
FTC CARS Rule Reg Z Audit Trail
Source: GET /api/admin/compliance — checks all vehicles for required disclosures (Buyer's Guide, price advertising, financing terms).
Audit log: Every compliance-relevant action is immutable — deal.signed, lead.status_change, settings.update all timestamped with actor.
PII handling: Customer PII (phone, email, SSN-adjacent fields) stored AES-256-GCM encrypted. Admin decrypts on-demand, access logged.
Data deletion: POST /api/privacy/delete-data — GDPR/CCPA right-to-erasure, full audit trail preserved without PII.
/admin/settings — Dealer Config + Security
MFA Enrollment Rate Limiting Session Control
MFA: POST /api/admin/mfa/setup — generates TOTP secret, QR code, 10 backup codes. POST /api/admin/mfa/verify enables MFA on account.
Login protection: Redis-backed rate limiter — 5 failed attempts triggers 15-min lockout. Resets on success. Falls back to in-memory for dev.
Session: JWT sessions max 8 hours, 30-min idle timeout enforced in middleware. MFA-pending sessions can only access /api/admin/mfa/verify.
Audit: PATCH /api/admin/settings → audit_log("dealer.settings.update") — every config change attributed to actor + session.

🧠 Micro-Behavioral Intelligence Pioneer

Five signals no other dealer platform captures. These detect subtle buying behaviors that reveal purchase intent before a customer fills out a form.

📸 Photo Comparison Dwell
Measures which vehicle a buyer lingers on when swiping between two. Longer dwell = stronger preference — detected before they tell you.
💰 Price Sensitivity Fingerprint
Tracks calculator inputs (60 vs 84 months, down payment amounts). Reveals real budget ceiling without asking. Bounce after price = sticker shock.
⚡ Decision Velocity
First VDP view → lead submit in under 1 hour = impulse buyer (call NOW). Over 3 days = comparison shopper (nurture, don't pressure).
📱→🖥️ Device Handoff Intent
Browse on phone at lunch, open same vehicles on desktop at home. Mobile-to-desktop with shared VINs = one of the strongest buying signals possible.
🌙 Night Owl Premium
9pm-midnight browsing = 40% higher purchase intent than business hours. They can't sleep thinking about that car. System scores these sessions 1.4x higher.

All 5 signals feed v_micro_signal_propensity — a combined modifier that adjusts each customer's lead score in real time. High velocity + device handoff + night owl = call them first.
