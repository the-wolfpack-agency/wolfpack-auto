### 5. Intelligence Systems (3 new)

**Predictive Lead Scoring** (`src/lib/predictive-lead-scorer.ts`)
- 20 weighted signals with temporal decay (today=100%, 7d+=10%)
- Outputs: score 0-100, buy probability, buy window (24h/3d/7d/14d/30d+), confidence, recommended action
- API: `/api/admin/leads/predict` (GET batch, POST single)
- Cron: `/api/cron/predict-leads` — daily at 6 AM UTC
- Leads page: predicted score column, buy window badge, sort by score

**Predictive Auto-Calibration** (`src/lib/prediction-calibrator.ts`)
- Compares predictions vs actual outcomes → adjusts signal weights
- Accuracy, precision, recall, F1 scoring
- Identifies top predictive and misleading signals
- Cron: `/api/cron/calibrate-predictions` — weekly Monday 2 AM UTC
- Analytics Brain: "Model Health" card

**Cross-Dealer Intelligence** (`src/lib/cross-dealer-intelligence.ts`)
- 8 insight types: market demand, pricing benchmark, conversion pattern, inventory velocity, engagement benchmark, feature adoption, seasonal trend, optimal pricing
- All anonymized — never exposes dealer names or customer PII
- API: `/api/admin/analytics/intelligence`
- Admin page: `/admin/market-intelligence`

**Real-Time Engagement Alerts** (`src/lib/engagement-alerts.ts`)
- 8 compound signal triggers (hot_return, price_serious, comparison_ready, repeat_viewer, budget_revealed, video_engaged, about_to_leave, competitor_risk)
- Priority: critical/high/medium — "call NOW" alerts
- 30-second polling, 2-hour expiry
- API: `/api/admin/alerts`
- Admin page: `/admin/alerts` + HotLeadsWidget on dashboard

**Additional Systems:**
- Lookalike engine (`src/lib/lookalike-engine.ts`) — "Shoppers Also Viewed" on VDP
- A/B testing (`src/lib/ab-testing.ts`) — deterministic variant assignment
- Push notifications (`src/lib/push-notifications.ts` + `public/sw.js`)

## Architecture Notes for Design Refresh

**Brand colors**: Single update in `src/app/globals.css` (CSS variables `--brand-*`, `--accent-*`, `--surface-*`)

**Copy/wording**: Inline in `.tsx` files. No CMS. Direct edits.

**Navigation**: Public nav in `src/app/layout.tsx`, admin sidebar in `src/components/AdminSidebar.tsx`

**Component structure**: All pages follow the same pattern (header → stats cards → filter bar → table/cards). Wireframe changes = component layout, not architecture.

**Test safety**: 2571 tests catch regressions immediately. Run `npx playwright test --project=chromium --workers=4` after any design changes.
