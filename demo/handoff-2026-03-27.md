## Architecture Reminders

- **Shadow mode**: Every API route checks `!process.env.DATABASE_URL` first, returns mock data. DB errors in catch block ALSO return mock data (not 500). This is what made the Hoxsie demo work.
- **Multi-tenancy**: Tenant resolved from subdomain in middleware → `x-dealer-slug` header → all API routes scope data by dealer_id.
- **Demo credential**: Hard-coded in `src/lib/auth.ts` `authorize()` function. No env var needed. Works everywhere.
- **MFA flow**: Password auth → if `mfa_enabled`, returns `mfa_required: true` → login page shows TOTP step → second `signIn()` call with `mfa_user_id` + `mfa_token`.
