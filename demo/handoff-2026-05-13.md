### Static analyzer (use it on apex next session)
Located inline in this session's bash output — paste it into a `scripts/check-migration-tree.py` for reuse. It builds a full table/view symbol table and reports the 5 bug classes. Runs in <1s.

Pattern of what it checks (5 classes):
1. FK type mismatch — `col TYPE REFERENCES tbl(col)` where types differ
2. ALTER/INDEX on never-created relations
3. FK referencing a VIEW (Postgres rejects)
4. Shadow CREATE TABLE (later mig redefines table; IF NOT EXISTS masks; downstream column refs fail)
5. Volatile functions (`NOW()`, `CURRENT_TIMESTAMP`) in CREATE INDEX `WHERE` predicates
