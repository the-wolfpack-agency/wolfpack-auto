## Memory notes worth carrying forward

- The **`URL.searchParams` `+` vs `%20` bug** (Microsoft Graph KQL silently returns 0 rows on `+`) is the single most expensive bug we hit today. If any future Graph integration uses `URL` / `URLSearchParams`, manually concatenate `+ encodeURIComponent(...)` instead. Already documented inline in `inbox-poller.ts`.
- The **shadow-store pattern** for missing-table degradation is now consistent across 6+ admin routes. Next time we see "POST 201 succeeds but GET shows nothing", that's the first thing to check.
- The **demo-account auth identity gotcha**: demo users have placeholder emails (`cto@wolfpack.dev`) that match no real Microsoft mailbox. Always feed `auth.user.id` to `getValidToken` (it does dual lookup on `connected_by OR user_email`).
