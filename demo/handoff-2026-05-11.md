## Stream 2: Four novel-method features for wolfpack-auto (commit 17b9410)

Four production-grade features built in parallel that legacy DMS structurally cannot match. All use mock providers by default with paid-provider stubs honestly labeled where partnerships are required for production rollout.

### Feature A: Live inventory valuation + market intel (migration 065)

Every vehicle auto-fetches NHTSA spec data (free public API), current market value (KBB mock + paid-provider stubs), comparable inventory nearby, days-on-lot vs market velocity. Dashboard surfaces pricing actions: HOLD, REPRICE_DOWN, REPRICE_UP, MOVE_TO_FRONT, MOVE_TO_BACK. Vercel cron refreshes nightly. Triple-write to Qdrant + Neo4j for similar-vehicle semantic queries. 66 new tests.

Key files: `src/lib/market-intel/`, `src/app/api/admin/vehicles/[vin]/market-intel/route.ts`, `src/components/admin/MarketIntelCard.tsx`.

### Feature B: Modern lead intake + auto-enrichment (migration 066)

Webhook + API + manual intake routes. HMAC-SHA256 signed bodies via `X-Webhook-Signature` + `X-Lead-Source-Id`. Auto-enrichment fans out in parallel via `Promise.allSettled` across mock provider + paid-provider stubs (Clearbit, FullContact, PropertyRecords). Rule-based 0-100 scoring across 6 factors. Specialization-aware routing to the right rep. 161 new tests.

Key files: `src/lib/leads/`, `src/app/api/leads/intake/route.ts`, `src/app/admin/leads/[id]/page.tsx`, `src/components/LeadEnrichmentPanel.tsx`.

### Feature C: Customer-facing pre-qualification flow (migration 067)

Public `/pre-qual` wizard. Soft credit pull, income verification, lender quote engine generates real offers in under 60 seconds. Customer arrives at lot already pre-approved. AES-256-GCM encryption on raw credit responses + Plaid tokens. Mock bureau + Plaid by default, real provider stubs (Experian/Equifax/TransUnion + Plaid) await partnerships. 96 new tests including Playwright E2E.

Key files: `src/lib/prequal/`, `src/app/api/prequal/[id]/{credit,income,offers}/route.ts`, `src/app/pre-qual/page.tsx` + `PreQualWizard.tsx`.

### Feature D: Real-time recall + TSB awareness (migration 068)

NHTSA recalls API (free public, 24h cache, fail-open). Vehicle-recall resolver. Service write-up screen flags critical recalls (red), moderate (yellow), TSBs (blue) before the writer touches the deal. Weekly cron pulls fresh recalls. Mark-resolved + dismiss workflows with audit trail. 81 new tests.

Key files: `src/lib/recalls/`, `src/app/api/admin/vehicles/[id]/recalls/route.ts`, `src/components/service/RecallsPanel.tsx`.

### Honesty corrections made during the session

Two material corrections worth preserving:

1. **Instinct repositioning.** Earlier framing positioned Instinct as a Claude Operator competitor. Corrected: Instinct is an AI cost-efficiency platform. Anthropic and OpenAI structurally cannot compete in this category because their revenue depends on token spend growing. Plus internal Wolfpack dogfooding sets a value floor independent of external market. Memory entry: `feedback_instinct_positioning.md`.
2. **Patent overstatement.** Earlier docs positioned utility patents (overlay architecture, compliance scanner, efficient AI orchestration) as primary moats. CTO challenged this. Corrected: prior art is extensive across all three, patents are speculative defensibility. Real moats are trade secrets, time-to-market, switching cost, data network effects, internal dogfooding credibility, distribution. Five docs updated to reflect honest framing. Memory entry: `feedback_honesty_over_enthusiasm.md`.

### NFC correction

Earlier IoT framing leaned on NFC tap workflows. CTO pushback: tap is friction, kills adoption, same pattern that made the timeclock hated. Corrected to passive detection (phone-as-tag via Wolfpack mobile app, passive BLE badges, passive UHF RFID gates, computer vision for unaffiliated customers). NFC reduced to narrow uses where the tap IS the natural action (keybox retrieval, customer walkaround, delivery signature).

### Scope discipline note

IoT and world-model content is year-two and year-three thinking, not a year-one build mandate. Year-one engineering stays on revenue-generating software (Wedge E compliance, Wedge D overlay, Instinct cost-efficiency). Architectural prep (event sourcing, sensor abstraction, empty spatial_events table) is the only year-one IoT work.
