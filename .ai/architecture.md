# Architecture — Wolfpack Auto

Multi-tenant dealer operating system (DOS) — inventory, leads, F&I desking, service, accounting/GL, payroll, analytics, dealer onboarding. Next.js App Router on Vercel with Postgres (Neon) as source of truth, Redis for hot cache + rate limiting, Elasticsearch for vehicle search, S3 for media, and a triple-write fan-out (Postgres + Qdrant + Neo4j) for learning entities.

## Data flow

```
HTTP request
  → middleware.ts           (auth cookies, tenant resolver, onboarding redirect, CSP, rate-limit headers)
  → app/api/.../route.ts    (requireAuth → capability/role check → checkRateLimit where public)
  → lib/<domain>.ts         (business logic)
  → lib/dms/* | lib/stripe-payments.ts | lib/elasticsearch.ts | lib/email.ts  (typed external wrappers)
  → lib/db.ts + src/db/queries/*  (Postgres — source of truth, RLS-scoped on tenant)
  → lib/redis.ts            (hot cache + rate limiter + circuit breaker)
  → lib/triple-write.ts     (Postgres + Qdrant vector + Neo4j edge)
  → lib/analytics-hooks.ts  (trackDeal / trackService / trackLead — module-scoped helpers)
  → lib/audit-log.ts        (append-only hash chain for security-relevant actions)
```

Key invariants:

- Public endpoints MUST `checkRateLimit()`; admin endpoints MUST `requireAuth()`. The canary + security-hardening tests enforce this.
- Every mutating admin route touches `audit_log` via `lib/audit-log.ts`.
- Every domain action emits a typed analytics event via `lib/analytics-hooks.ts` — event strings are unions, typos fail at compile time.

## Triple-write pattern

`lib/triple-write.ts` is the single durable writer for learning entities (leads, interactions, conversations, trade-in evaluations, walkaround sessions). Postgres is source of truth; Qdrant is semantic index; Neo4j is relationship graph. If Qdrant or Neo4j is down, the Postgres write still succeeds and a `system.triple_write_degraded` event is emitted.

## Multi-tenant isolation

- Every row carries `dealer_id` (or `tenant_id`); RLS policies enforce isolation (migration 055 `enforce_rls.sql` is the bar — see `verify-rls.ts`).
- `src/lib/tenant-resolver.ts` maps hostname / path / session → `dealer_id` before the request reaches the route handler.
- `src/lib/tenant-context.ts` carries that `dealer_id` into every DB call; do not accept `dealer_id` as a user-controlled parameter.

## Auth model

NextAuth (JWT sessions) + custom MFA (migration 020, `otpauth` + QR). Middleware auto-redirects `/admin` → `/admin/getting-started` when `onboarding_complete` cookie is `"false"`. `requireAuth()` in `src/lib/auth-guard.ts` is the single gate.

Vercel (project `wolfpack-auto`). `build` runs `openapi → next build`. Canary deploy gated by `scripts/canary-post-deploy.sh`; predeploy gate is `scripts/predeploy-gate.sh`.
